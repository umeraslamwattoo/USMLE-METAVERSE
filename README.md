# USMLE-METAVERSE

Full-stack app.

- `frontend/` — React (Create React App)
- `backend/` — Node.js / Express + MongoDB

## Setup

```bash
# backend
cd backend && npm install
cp .env.example .env   # fill in values
npm start

# frontend
cd frontend && npm install
cp .env.example .env   # fill in values
npm start
```
